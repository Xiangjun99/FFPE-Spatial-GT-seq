# RNA Type-specific Expression Matrix Generation from Spatial FFPE-GT-seq Data

This repository provides a workflow for generating RNA type-specific expression matrices from Spatial FFPE-GT-seq RNA sequencing data.

## Overview

The workflow consists of two major steps:

### Step 1: Generate Gene Expression Matrix using ASTRO

Spatial transcriptomics data are first processed using **ASTRO** to generate the complete RNA expression matrix.

ASTRO repository:

https://github.com/gersteinlab/ASTRO

The output of ASTRO serves as the input for downstream RNA type-specific analysis.

### Step 2: Split Expression Matrix by RNA Type

The script `split.R` separates the ASTRO-generated expression matrix into individual RNA type-specific matrices.

Examples of RNA types include:

* mRNA
* lncRNA
* snRNA
* snoRNA
* miRNA
* rRNA
* pseudogene
* other annotated transcript classes

Each RNA type is exported as an independent expression matrix for downstream analyses.

## Input Files

### 1. ASTRO Expression Matrix

Gene-by-spot (or gene-by-cell) expression matrix generated by ASTRO.

Example:

```text
gene_id    Spot1    Spot2    Spot3
GeneA      10       5        8
GeneB      0        3        1
...
```

### 2. Gene Annotation File

Annotation table containing gene biotype / RNA type information.

Example:

```text
gene_id    gene_name    rna_type
GeneA      ABCD1        mRNA
GeneB      LINC001      lncRNA
...
```

---

## Usage

### Run ASTRO

Follow the instructions provided in the ASTRO repository:

https://github.com/gersteinlab/ASTRO

Generate the complete expression matrix.

### Run RNA Type Splitting

```bash
Rscript split.R \
    expression_matrix.tsv \
    gene_annotation.tsv \
    output_directory/
```

---

## Output

The script generates one expression matrix per RNA type.

Example output structure:

```text
output_directory/

├── mRNA_expression.tsv
├── lncRNA_expression.tsv
├── snRNA_expression.tsv
├── snoRNA_expression.tsv
├── miRNA_expression.tsv
├── rRNA_expression.tsv
└── summary_statistics.tsv
```

---

## Example

```bash
Rscript split.R \
    ASTRO_expression_matrix.tsv \
    gene_annotation.tsv \
    RNA_type_matrices/
```

* Differential expression analysis

* Multi-modal spatial omics integration
