# Spatial-FFPE-GT-seq

This repository contains the code for the manuscript "Spatial genome-transcriptome co-mapping reveals tumor heterogeneity in FFPE tissues". In this work, we develop Spatial FFPE-GT-seq, a platform for joint spatial profiling of DNA, RNA, non-coding RNAs and, in an extended format, immune-related proteins from the same FFPE section at single-cell resolution. This platform establishes Spatial FFPE-GT-seq as a broadly applicable framework for resolving clonal evolution, transcriptional reprogramming and non-coding RNA programs directly in clinically archived human tumors.
